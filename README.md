# 🌸 Bloom OS

### Seu espaço para florescer.

**Bloom OS** é uma aplicação web de organização pessoal, produtividade e autocuidado, desenvolvida para transformar o planejamento cotidiano em uma experiência intuitiva, acolhedora e visualmente sofisticada.

O projeto reúne diferentes aspectos da vida em um único ambiente digital, combinando funcionalidades práticas com uma interface inspirada no minimalismo feminino e no design editorial contemporâneo.

*Organize sua rotina. Cultive seus hábitos. Floresça no seu ritmo.*

---

## ✦ Sobre o projeto

O Bloom OS nasceu da ideia de que produtividade e bem-estar podem coexistir em uma mesma experiência.

Mais do que um gerenciador de tarefas, a proposta é oferecer um espaço pessoal no qual organização, aprendizado, planejamento financeiro e autocuidado estejam conectados.

O desenvolvimento prioriza três pilares:

- **Experiência:** navegação intuitiva, responsividade e interações fluidas.
- **Design:** identidade visual delicada, consistente e funcional.
- **Personalização:** ferramentas que se adaptam às necessidades e à rotina de cada pessoa.

## ✦ Tecnologias

O projeto utiliza:

- **React** — construção de interfaces e componentes.
- **TypeScript** — tipagem e organização do código.
- **Vite** — ambiente de desenvolvimento e build.
- **Tailwind CSS** — estilização e design responsivo.
- **Git & GitHub** — versionamento e gerenciamento do projeto.

O desenvolvimento começou com uma base criada no Lovable e evoluiu por meio do VS Code e de ferramentas de programação assistida por inteligência artificial, com foco na experiência, na implementação das funcionalidades e na manutenção do código.

## ✦ Executando localmente

Para executar o projeto, é necessário ter o Node.js e o npm instalados.

Clone o repositório:

```bash
git clone https://github.com/nathalyferraz-ui/bloom-os.git
```

Acesse a pasta:

```bash
cd bloom-os
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Abra no navegador o endereço local informado pelo Vite.
